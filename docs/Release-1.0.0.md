# QuotaNotch 1.0.0

首个正式版本：在 MacBook 刘海中查看 AI 额度、控制音乐和查看日历。

- 支持 Claude、Codex，以及可选的 Gemini CLI / Code Assist 额度。
- 固定一个额度与音乐共享刘海；左右悬停进入对应页面。
- 额度不足时渐变为黄色、红色，并带轻微光晕；可开启圆环数字。
- 保留音乐暂停后的驻留时间，支持中文与英语。

**安装：** 下载 `QuotaNotch-1.0.0.dmg`，打开后拖入「应用程序」。更新前先退出 QuotaNotch。本机 CLI 需先完成登录。

macOS 15+，支持 Apple Silicon 和 Intel。安装包尚未 Apple 公证；首次打开可能需要在「隐私与安全性」中允许。当前通过 GitHub Releases 手动更新。

---

The first stable release: AI quota, music and calendar in your MacBook notch.

- Claude, Codex and optional Gemini CLI / Code Assist quota.
- One pinned quota alongside music, with hover opening the corresponding side.
- Subtle low-quota color transitions and glow, plus optional ring numbers.
- Music pause residency, English and Simplified Chinese.

**Install:** Download `QuotaNotch-1.0.0.dmg`, open it and drag QuotaNotch into Applications. Quit QuotaNotch before updating. Sign in to your local CLI before enabling monitoring.

Requires macOS 15+; universal Apple Silicon / Intel app. Ad-hoc signed, not Apple notarized. Updates install manually from GitHub Releases.
